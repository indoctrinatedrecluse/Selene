## 🚀 How to Open in Selene

- **In the Web App**:
  - Click **Open File** (`Ctrl+O`) in the top navigation bar or select from the Samples sidebar folder.
- **In Desktop Shell** (Tauri):
  - Open via the native file picker or mount local workspace directories directly.
- **In Mobile App** (Flutter):
  - Tap **Samples Gallery** on the Home Screen to preview or clone any template into your mobile library.
